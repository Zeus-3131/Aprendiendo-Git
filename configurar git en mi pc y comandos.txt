configurar git en mi pc y comandos basicos 

comandos para configurar las credenciales del repositorio personal o corporativo

$ git config --global user.name "Jonathan"

$ git config --global user.email "queleimporta545@gmail.com"

$ git config --list

$ git config user.name
Jonathan

$ git config user.email
queleimporta545@gmail.com


comandos para configurar las llaves ssh con github 

$ ssh-keygen -t ed25519 -C "queleimporta545@gmail.com"

$ eval "$(ssh-agent -s)"       para que funcione este comando ejecute estos comandos en powershell como administrador

                                Set-Service -Name ssh-agent -StartupType Manual
                                Start-Service ssh-agent
                                Get-Service ssh-agent

$ clip < ~/.ssh/id_ed25519.pub             para que funcione este comando es el de revisar la ruta ~/.ssh/id_ed25519.pub

$ cat ~/.ssh/id_ed25519.pub | clip.exe     este comando va a copear la llave ssh en el portapales para copearla en github

$ ssh -T git@github.com                    este comando es para revisar si la conexion con github y la cuenta del pc esta configurada correctamente




comando Add

git add 

git add index.js        agregar los cambios de un archivo especifico

git add *.js            agregar los cambios de archivos con una terminacion 

git add src/component-*  agregar los cambios de archivos que segan un patron 

git add .              agregar los cambios de todos los archivos bajo el directorio actual

git add -A             agrega todos los archivos con cambios en el proyecto hace lo mismo que el add . pero en la carpeta o directorio actual no en todo el proyecto 

git add -u             agregar todos los archivos modificados o eliminados 

git reset              devuelve cambios en archivos a la zona de trabajo


comando Commit

git commit 

     al insertar el comando git commit se abrira la consola vim y estos son los pasos para salir de la consola 

     Presiona la tecla Esc (para asegurarte de no estar en modo edición).
     Escribe :wq (los dos puntos son necesarios; significa write & quit).
     Presiona Enter.

git commit -m "mensaje de ejemplo"    esta es la manera para que no se ejecute o se abra la consola vim de git sino que uno solo ingresa el mansaje y ya 

git log              es un comando para revisar los log o los commits realizados atravez del tiempo

git log --oneline    es un commando para revisar los log o commits pero de una forma mas ordenada




comando para respositorio remoto 

git push      funciona para enviar los cambios del repositorio local a el repositorio remoto en este caso github 

git pull      funciona para actualizar del repositorio remoto a el repositorio local con sus respectivos cambios  

git branch    funciona para revisar en que rama se esta situada o para realizar el cambio a la rama necesaria 

git push -u origin main     este comando sirve para subir el contenido del repositorio local al repositorio remoto 


ramas

git switch -C (nombre de la rama)           es para crear una nueva rama 

git switch                                  se utiliza para cambiar de rama 

git branch                                  es para revisar en que rama se encuentra 

git branch -d (nombre de la rama)           es para eliminar una rama y para usarlo se debe estar en una rama diferente a la que desea eliminar



Desacer cambios

git checkout (nombre del archivo)           este comando se utiliza para descartar los cambios de los cambios hechos en el archivo seleccionado

git checkout .                              este comando se utiliza para descartar los cambios pero de todo el proyecto hechos la ultima vez 


unir ramas

git merge (nombre de la rama que quiere unir)   sirve para unir ramas 


modificar commits 

git commit --amend                       Edita el último commit (cambia mensaje o agrega archivos)

git show                                 Muestra los cambios detallados del ultimo commit 

git revert [hash]:                       Crea un nuevo commit que deshace los cambios del commit especificado. Se abrirá el editor para que confirmes el mensaje del commit.

git cherry-pick [hash]:                  Trae un solo commit específico de cualquier rama a la tuya.
